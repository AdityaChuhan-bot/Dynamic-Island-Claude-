# Dynamic Island (Android)

An original Android implementation of an iOS-style Dynamic Island overlay.

**Build status:** source has not yet been compiled or tested.

## Build

The repository includes a GitHub Actions workflow to build a debug APK. Open **Actions**, select **Build Debug APK**, and run the workflow. Download the `dynamic-island-debug-apk` artifact after the workflow succeeds.

## Permissions

On first launch, grant display-over-other-apps permission and notification access. Notification data is processed locally by the app.
